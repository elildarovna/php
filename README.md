# «Рядом» — сайт психологической помощи

Учебная демонстрация варианта **«готовый Frontend с заглушками контроллеров»**. Это одностраничный сайт на Symfony и Twig: информация об услугах, специалисты, описание записи, FAQ и адаптивная верстка для телефона и компьютера.

## Запуск

Из корня проекта выполните:

```bash
composer install
php -S 127.0.0.1:8000 -t public
```

Откройте `http://127.0.0.1:8000/`.

## Что уже работает

- Главная страница открывается по адресу `/`.
- Ссылки навигации прокручивают к разделам сайта.
- Частые вопросы раскрываются нажатием.
- Форма проверяет обязательные поля браузером и показывает демонстрационный ответ.
- Карточки специалистов передаются из Symfony-контроллера в Twig-шаблон.

## Заглушки демонстрационной версии

Форма записи не отправляет и не хранит данные. Подбор психолога, аккаунты, оплата и видеозвонки не подключены. Список специалистов задан в контроллере как пример данных; его можно заменить данными из базы на следующем этапе.
