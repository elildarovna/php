# Домашнее задание 8 — сайт «Точка опоры»

Отдельный учебный Symfony-проект с тремя страницами: главная, о проекте и контакты. Тексты страниц есть на русском и английском языках. Язык хранится один раз в `var/site_language`, поэтому настройка общая для всех посетителей и всех страниц.

## Установка и запуск

Выполните команды в папке `homework8`:

```bash
composer install
php -S 127.0.0.1:8000 -t public
```

Откройте `http://127.0.0.1:8000/`.

## Сменить язык всего сайта

В другом окне терминала, также из папки `homework8`, выполните:

```bash
php bin/console app:language:change en
```

Чтобы вернуть русский:

```bash
php bin/console app:language:change ru
```

Обновите страницу в браузере. Команда меняет общий файл настройки, а не язык отдельного пользователя.
